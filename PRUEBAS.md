# Prueba en celulares reales (antes de enviar el link a candidatos)

Hazla **una vez en un Android (Chrome)** y **una vez en un iPhone (Safari)**. Toma unos 15 minutos por celular.
Ten a mano: una foto tuya con fondo blanco y 5 o 6 PDF cualquiera que tengas (pueden ser tus propios certificados).

Link: https://felipeanali.github.io/GuiadearchivosHV/

Marca cada punto con ✅ o ❌. Si algo sale ❌, toma pantallazo y anota en qué celular pasó.

## 1. Abrir la página
| # | Qué hacer | Qué debe pasar | Android | iPhone |
|---|---|---|---|---|
| 1 | Abre el link en Chrome / Safari | Aparece "Cargando…" un momento y luego la página | | |
| 2 | Toca **¿Necesitas ayuda?** | Se abre el manual en PDF (en Android puede descargarse y abrirse desde la notificación) | | |
| 3 | Toca **Leer la política** (abajo, en Tratamiento de datos) | Se abre la política en la página de Cañaveral | | |

## 2. Dentro de WhatsApp e Instagram
| # | Qué hacer | Qué debe pasar | Android | iPhone |
|---|---|---|---|---|
| 4 | Envíate el link por **WhatsApp** y ábrelo desde el chat | La página abre. Anota si sale el aviso amarillo "Abre esta página en…" (en WhatsApp normalmente NO sale) | | |
| 5 | Pon el link en tu **bio o un mensaje de Instagram** y ábrelo desde Instagram | Sale el aviso amarillo "Abre esta página en Chrome/Safari" | | |
| 6 | En Android toca **Abrir en Chrome** / en iPhone sigue los pasos del aviso | La página se abre en Chrome / Safari | | |

## 3. Recorrido completo (en Chrome / Safari)
| # | Qué hacer | Qué debe pasar | Android | iPhone |
|---|---|---|---|---|
| 7 | Responde las preguntas, elige **"Sí, es mío"**, acepta y toca Comenzar | Pasa a "Tus datos" | | |
| 8 | Escribe nombre, cédula y empieza a escribir un cargo | Salen sugerencias; al tocar una se llena | | |
| 9 | Sube la **foto** desde la galería | Se acepta. Prueba también **tomarla con la cámara** | | |
| 10 | Sube un PDF en un documento que **no** corresponde (ej. el de EPS en Diplomas) | Lo rechaza con un mensaje claro | | |
| 11 | Sube cada PDF en su lugar | Cada uno queda con ✓ | | |
| 12 | **Cierra el navegador** del todo y vuelve a abrir el link | Vuelve a tus documentos, sin perder nada | | |
| 13 | Toca Continuar y luego **Descargar paquete** | Se descarga el ZIP. Anota dónde quedó (Descargas / Archivos) | | |
| 14 | Toca **Abrir página de subida** y sube el ZIP | El ZIP se sube a OneDrive sin error | | |
| 15 | Vuelve y toca **Ya lo subí, borrar mis datos** | Sale la pantalla final | | |

## 4. Corrección (link que manda Gestión Humana)
| # | Qué hacer | Qué debe pasar | Android | iPhone |
|---|---|---|---|---|
| C1 | En el panel (`panel-gh.html`), abre al candidato de prueba, rechaza un documento y toca **Pedir correcciones → Abrir WhatsApp** | Llega por WhatsApp el mensaje con el link | | |
| C2 | Abre el link desde WhatsApp | Sale "Corrige tus documentos" con el motivo en rojo | | |
| C3 | Escribe un número de documento equivocado | "Ese número no coincide…" y no deja seguir | | |
| C4 | Escribe el número correcto, sube el documento y descarga el paquete | Se descarga `CEDULA_CORRECCION_1.zip` | | |
| C5 | Súbelo con **Abrir página de subida** y procésalo en el panel | En la ficha el documento queda pendiente y "llegó en la corrección 1" | | |

## 5. Revisión en Gestión Humana
| # | Qué hacer | Qué debe pasar |
|---|---|---|
| 16 | Abre la carpeta de OneDrive y descarga el ZIP que llegó | Están todos los archivos con nombre `CEDULA_NN_DOCUMENTO.pdf` |
| 17 | Abre `00_LEEME_REVISION.txt` | Dice qué archivos revisó la página y cuáles hay que mirar a mano |

## Si algo falla
Anota: celular (marca y modelo), navegador, en qué paso pasó y el mensaje que salió (pantallazo).
